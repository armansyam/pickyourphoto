Bagaimana Cara Kerja Pemisahan File RAW Pilihan Klien?

Sistem menghubungkan galeri seleksi digital dengan file foto asli di komputer Anda secara aman tanpa mengunggah file mentah berukuran besar ke server.

Otomatisasi 1-Klik RAW Sorter

Fitur Automatic RAW Sorter secara cerdas memindai folder lokal Anda, lalu memindahkan file fisik RAW (.CR3, .NEF, .ARW, .DNG) yang cocok ke folder baru SELECTED_RAW secara instan.

Pencarian Berbasis Nama File

Bagi Anda yang memilih metode manual, daftar nama file dipisah spasi tanpa ekstensi. Pencarian nama akan menemukan seluruh format file dengan nama sama (JPG & RAW) di sistem operasi dan software edit favorit Anda.

Pilih Metode Sortir Sesuai Software & Perangkat Anda

Gunakan fitur unggulan 1-Click Automatic RAW Sorter untuk pemisahan otomatis 100% lokal, atau pilih tab software/sistem operasi yang biasa Anda gunakan di bawah ini.

Salin Nama File dari Dashboard

Buka Folder Foto RAW di Komputer

Buka folder di komputer atau harddisk eksternal yang menyimpan seluruh file foto RAW asli dari sesi tersebut.

Jalankan 1-Click RAW Sorter

Jalankan fitur Automatic RAW Sorter di folder tersebut dan tempelkan daftar nama file yang sudah disalin.

Selesai — File RAW Terpisah Otomatis

Seluruh file fisik RAW pilihan klien secara otomatis terkumpul rapi di folder baru SELECTED_RAW. Siap di-import ke Lightroom!

100% Lokal & Privasi Aman: Proses sortir RAW bekerja sepenuhnya offline di komputer Anda. File RAW berukuran besar tidak perlu diunggah ke server.
Cocok untuk mengumpulkan RAW + JPG hasil pilihan klien ke satu folder baru, sebelum masuk ke software edit apapun.

Open original photo folder

Open the folder storing all the shots (RAW and JPG) from that photo session.

Click the search bar

Click the magnifying glass icon in the top-right corner of the Finder window.

Paste the filename list

Paste using Cmd + V. Finder will instantly display every file whose name matches the list — both RAW and JPG of the same name will appear.

Select all results

Press Cmd + A to select all displayed files, then Cmd + C to copy.

Collect in a new folder

Create a new empty folder, open it, then paste using Cmd + V. All selected files are now gathered in one place.

Catatan Catatan: Kolom pencarian Finder punya batas sekitar 2.048 karakter atau ±99 nama file dalam satu kali tempel. Kalau daftar dari klien lebih panjang dari itu, bagi dan tempel bertahap per beberapa puluh nama.
Sama seperti Finder, hasil akhirnya folder baru berisi file-file yang dipilih klien, siap dikirim ke editor atau di-import ke software manapun.

Open original photo folder

Open the folder storing all the shots from that photo session.

Click the search box

Click the "Search" box in the top-right corner of the File Explorer window.

Paste the filename list

Paste using Ctrl + V. Explorer automatically filters and displays matching files, including RAW and JPG of the same name.

Select all results

Press Ctrl + A, then Ctrl + C to copy all displayed files.

Collect in a new folder

Create a new empty folder, open it, then paste using Ctrl + V.

Catatan Catatan: Kolom pencarian Explorer punya batas lebih ketat, sekitar 259 karakter sekali tempel. Untuk daftar panjang, tempel dan proses secara bertahap — misalnya 15–20 nama per batch.
Cara paling cepat — tidak perlu menduplikat file fisik ke folder baru, langsung filter di dalam katalog Lightroom.

Pastikan foto sudah ter-import

Buka Lightroom Classic dan pastikan folder atau katalog berisi foto sesi ini sudah masuk ke Lightroom.

Jangkau semua foto

Klik All Photographs di panel Catalog sebelah kiri, atau pilih folder proyek terkait, supaya pencarian mencakup seluruh foto yang mungkin ada di daftar.

Buka Library Filter Bar

Tekan tombol \ atau klik area filter di atas tampilan grid, lalu pilih kategori Text.

Atur ke Filename / Contains

Ubah dropdown pertama menjadi Filename dan dropdown kedua menjadi Contains — bukan "Contains All", karena itu akan mencari nama yang mengandung semua kata sekaligus.

Tempel daftar nama

Klik kotak pencarian, tempel dengan Cmd/Ctrl + V. Semua foto yang namanya cocok langsung muncul di grid, RAW dan JPG sekaligus.

Simpan sebagai Collection

Tekan Cmd/Ctrl + A untuk memilih semua hasil, lalu buat Collection baru agar mudah dibuka kembali saat proses edit.

Penting Penting: Nama file di daftar harus dipisah spasi atau koma — bukan satu nama per baris, karena filter tidak akan bekerja jika ada baris baru. Tombol salin di dashboard sudah otomatis memformat ini untuk Anda.
Info Perlu diketahui: Fitur ini hanya ada di Lightroom Classic. Di Lightroom versi cloud (bukan Classic), pencarian nama file baru bisa dilakukan satu per satu.
Untuk yang mengedit di Capture One, bukan Lightroom — fitur ini bawaan resmi dari Capture One.

Pertanyaan yang Sering Diajukan

Kenapa hasil pencariannya kosong, padahal sudah ditempel?

Untuk Lightroom, pastikan nama dipisah spasi atau koma — bukan satu nama per baris. Untuk Finder/Explorer, pastikan folder yang dibuka memang berisi file aslinya, dan coba tempel dalam jumlah lebih sedikit dulu kalau daftarnya panjang.

Kenapa file RAW ikut muncul padahal saya cuma menyalin nama dari galeri JPG?

Karena pencarian bekerja berdasarkan nama file tanpa memedulikan ekstensi. Semua file dengan nama sama — baik .jpg maupun .CR2/.NEF/.ARW — akan ikut ditemukan. Ini memang disengaja supaya file RAW asli otomatis ikut terbawa.

Daftar nama dari klien saya sangat panjang, apa yang harus dilakukan?

Bagi daftar menjadi beberapa bagian lalu tempel bertahap — terutama di Windows Explorer yang batasnya lebih ketat (±259 karakter). Finder bisa menampung lebih banyak (±99 file), dan Lightroom Classic pada praktiknya bisa menampung daftar yang jauh lebih panjang dalam satu kali tempel.

Saya tidak pakai Lightroom atau Capture One, apa masih bisa?

Bisa. Cukup gunakan cara Finder (Mac) atau Explorer (Windows) untuk mengumpulkan file ke folder baru, lalu buka folder tersebut di software edit apapun yang Anda pakai.
