## Langkah-langkah yang Dilakukan  
1. **Nonaktifkan watchdog** (Hermes Agent) untuk menghindari konflik.  
2. **Bersihkan folder build** dengan `rm -rf .next`.  
3. **Jalankan build** dengan `npm run build` (sukses).  
4. **Restart PM2** dengan `pm2 restart pick-your-photo`.  
5. **Verifikasi status**: `pm2 show pick-your-photo` → `online`.  
6. **Buat laporan audit** sebagai `AUDIT_012`.  

## Rekomendasi  
- **Jangan gunakan watchdog** yang berinteraksi langsung dengan server selama build/restart.  
- **Pastikan build directory bersih** sebelum PM2 restart.  
- **Verifikasi build** dengan `ls -la .next` sebelum restart.  
- **Tambahkan pre-check** di script build: `test -f .next/BUILD_ID || echo "Build belum selesai"`
