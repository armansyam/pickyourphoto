## 3. Root Cause Analysis
- **Bus Error (SIGBUS)** terjadi saat proses `node` (Next.js build) mencoba mengakses memori virtual yang tidak tersedia di RAM maupun swap ZRAM.
- **ZRAM** melakukan kompresi di RAM — saat kompilasi Next.js membutuhkan alokasi memori besar (node_modules ≈ 200 MB + compile-time assets), ZRAM kehabisan kapasitas dan kernel mengirim SIGBUS.
- **Penyebab utama:** ZRAM tidak cukup untuk beban kompilasi berat. Dibutuhkan **file swap konvensional** (di disk) sebagai fallback.

> **Kesimpulan:** Masalah **infrastruktur server (ops)** — bukan kode aplikasi. ZRAM perlu dilengkapi dengan swap file konvensional agar build tidak terkena SIGBUS.
