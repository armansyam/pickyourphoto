## 3. Pemeriksaan Crash Root‑Cause
1. **Bus Error** terjadi pada langkah *Creating an optimized production build …* – langkah di mana Next.js menghasilkan `.next` assets.  
2. **Segfault/SIGBUS** pada proses `node` memiliki akibat umum:  
   - **Out‑Of‑Memory (OOM) Killer** membunuh proses node.  
   - Driver GPU/virtualisasi LXC mungkin tidak ramah pada alokasi memori besar pada Node‑JIT.  
   - Node.js 20.x pada LXC dengan 1.2 GiB RAM tersedia **tidak cukup** untuk `next build` pada kode basis yang memiliki banyak dependensi (≈ 200 MB node_modules + compile‑time assets).  
3. **Memtrace/ULimit** tidak menunjukkan batas ukuran core, melainkan kernel mencatat `Out of memory: Kill process 564160 (node) score 987 or sacrifice child`. (lihat `/var/log/syslog` pada LXC).  

> **Kesimpulan Root‑Cause:** *Kurangnya memori (RAM + swap) pada LXC 102 menyebabkan Node.js/Next.js menghambat dan meng-trigger SIGBUS saat memproses dependensi besar pada tahap build*.

## 4. Rekomendasi Solusi Operasional
| No. | Solusi | Dampak | Prioritas |
|-----|--------|--------|-----------|
| 1️⃣ | **Tambah swap**: `dd if=/dev/zero of=/swapfile bs=1M count=2048 && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab` | Menambah ruang penampung memori, menghindari OOM‑kill. | **Wajib** |
| 2️⃣ | **Perkecil dependensi front‑end**: jalankan `npm prune --production` atau gunakan `npm ci --only=production` untuk mengurangi node_modules yang di‑install di runtime. | Mengurangkan memori yang diperlukan pada `next build`. | **Sangat Disarankan** |
| 3️⃣ | **Gunakan CI Build di eksternal runner** (mis. GitHub Actions, atau server dengan memori > 2 GiB) lalu *scp* hasil `.next`/`build` ke LXC 102. | Build occurs where memory is abundant; LXC hanya men-serv static assets. | **Opsional** |
| 4️⃣ | **Monitor swap usage**: `systemctl enable zram-config && swapoff -a && swapon -a` dan konfigurasikan `zram` untuk kompresi memori. | Menyediakan memori virtual yang lebih responsif pada I/O‑bound workloads. | **Disarankan** |
