## 3. Root Cause
Fungsi `generateToken` di `lib/auth.js` menggunakan default expiry `7d` untuk kepercayaanan development, tapi protokol Zero-Defect menuntut **masa berlaku token 24 jam** untuk produksi (mengurangi risiko token theft).  

---

## 4. Rekomendasi Perbaikan (Untuk Antigravity)
Ubah baris berikut di `/DATA/AppData/pickyourphoto/lib/auth.js`:

**Sebelum:**
```js
export function generateToken(payload) {
    return jwt.sign(payload, getJwtSecret(), { expiresIn: '7d' });
}
```

**Sesudah:**
```js
export function generateToken(payload) {
    return jwt.sign(payload, getJwtSecret(), { expiresIn: '24h' });
}
```

Setelah itu:
```bash
cd /DATA/AppData/pickyourphoto
git add lib/auth.js
git commit -m "fix: set JWT expiry to 24h for security compliance"
git push origin main
```
